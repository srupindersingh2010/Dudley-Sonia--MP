## Detailed audit notes

# Parliamentary specialist source audit

- Hansard: **working**. Official documented endpoint `https://hansard-api.parliament.uk/search/contributions/Spoken.json?queryParameters.memberId=5274&queryParameters.take=20&queryParameters.orderBy=SittingDateDesc`. The simple `/search.json?MemberId=5274` is wrong for this purpose (can return broad search / time out). Verified returned MemberId on every result. API reports 199 spoken contributions; 20 shown, direct debate/contribution links. Official Swagger at `https://hansard-api.parliament.uk/swagger/docs/v1`.
- EDMs: **working**. `/EarlyDayMotions/list?parameters.memberId=5274&parameters.includeSponsoredByMember=true`. Crucial `parameters.` prefix. Four records returned including one primary sponsorship. Fetches each detail and independently verifies Sonia's signature, including withdrawals. Official Swagger at `https://oralquestionsandmotions-api.parliament.uk/swagger/docs/v1`.
- Bills: **working for listed sponsorship**. `https://bills-api.parliament.uk/api/v1/Bills?MemberId=5274`. One result: Access to Finance for Women in Business Bill (4038), verified lead sponsor in Bill detail. Pagination implemented. API sponsor list may not include every supporting MP named in proceedings: limitation displayed; do not imply an exhaustive list of co-supporters. Swagger at `https://bills-api.parliament.uk/swagger/v1/swagger.json`.
- APPGs/PPS: **no dedicated Member API endpoint**. Official Members API Biography gives government/opposition/other posts and committees, but does not promise a complete PPS or APPG list. Public APPG officer page https://members.parliament.uk/member/5274/appgofficerroles is Cloudflare-blocked to plain requests from this environment. Link directly and say current APPG/PPS roles need office confirmation. Do not infer 'none' from empty government posts. Parent handles broader Biography roles.

Adapters implemented in scripts/parliament_sources.py, exporting SOURCES; each throws on malformed or unverified membership responses so last-good caching can preserve previous data.

# Dudley local-source audit

Checked 3 November 2026. Local source module: scripts/local_sources.py.

- **Dudley Council meetings: works, with coverage limit.** Dudley uses CMIS rather than Modern.gov. https://dudley.cmis.uk.com/Meetings.aspx exposes a JSON-encoded appointments array in its HTML. Parser decodes JSON safely and filters next 30 days. Current calendar includes 13 upcoming meetings through 1 December. The public default view cannot guarantee an entire rolling 30-day window in every month, so section explicitly notes this limit. Committee IDs are dynamically resolved from https://dudley.cmis.uk.com/Committees/2015Onwards.aspx to form tested working agenda links. Agenda URLs require the Committee ID (omitting it returns an error page despite HTTP 200). Attempting Telerik next-month POST resulted in a server critical-error response; do not treat that as a valid empty calendar.
- **WMCA meetings: works.** https://governance.wmca.org.uk/mgCalendarAgendaView.aspx?MR=0 returns several future months. Dates, agenda links, meeting names and venues parse from the official agenda view. Four meetings in current next-30-day window.
- **Profile: partially works, real numbers.** https://www.nomisweb.co.uk/reports/lmp/wpca24/721420430/report.aspx is the ONS/Nomis profile for Dudley constituency on 2024 boundaries (ONS code E14001204). Dynamic parser retrieves working-age population, employment, and claimant count with their published periods. Day-one values: population ages16–64 64,743 (2024); employment 46,700 /72.2% (Jul2025–Jun2026); claimant count 3,610 /5.6% (Sep2026). It does not mislabel borough data or working-age population as total population.
- **Profile gaps:** Commons Library dashboard and current population Excel https://researchbriefings.files.parliament.uk/documents/CBP-10529/population_by_age.xlsx return HTTP403 to this server. Health repository houseofcommonslibrary/local-health-data-from-QOF contains old constituency boundaries and 2019/20 data, so it is unsuitable for current Dudley and intentionally unused. Health, housing and total-population official dashboards are linked with explicit numeric-ingestion limits. Nomis census API attempted with GSS and numeric geography identifiers returned empty payloads for these new-boundary series, so not used.
- **MP news: partial.** https://sonia-kumar.co.uk/feed/ and its www variant/WP JSON endpoint return HTTP403. BBC regional RSS works, filtered to exact Sonia Kumar name mentions (can validly have none). Google News RSS query for the exact name works and gives local newspaper headlines plus links, no article copying. Each feed is checked separately and source_checks exposes MP-site failure even while aggregate news succeeds. No unverified Express & Star RSS URL is used (tested URL returned 404).
- **Community events: works as requested links.** Council events source https://www.dudley.gov.uk/things-to-do/events/ works and supplies council listings, Discover Dudley, Himley Hall, community directory links. Eventbrite is a third-party link (not an automated events feed), labelled accordingly. No claim that Sonia attends these community events.
- **Useful links: works as curated directory.** Council, road reporting, NHS, benefits, Citizens Advice, Black Country Foodbank, cost-of-living support and community directory. Council root, roads, Citizens Advice https://www.citizensadvicedudley.org/ and foodbank verified HTTP200. The legacy long Citizens Advice domain has a certificate mismatch and is not used.
- **Public diary:** user clarified already-public events only, no private diary/calendar setup. No office calendar is connected or private information fetched. Root handles public announcement links; do not infer event dates from an article publication date.

## Subsequent improvements (supersede gaps above)

- Council fetch now supplements the calendar with all current committee schedule pages in bounded parallel requests. Each committee gets its own last-good cache in the JSON payload; failures retain those records and appear in source_checks. This extends beyond the calendar month. Appointment links require committee IDs, resolved from the current committee index. Cancelled committee schedule entries are explicitly labelled.
- News now persists independent per-feed snapshots both in .cache/news.json and the committed news JSON feed_cache. An own-site failure does not discard previously retrieved own-site stories when BBC/Google work. Each feed retains last-good retrieval time and status.
- **Total population works:** ONS Nomis NM_2014_1 accepts geography=721420430, gender=0, c_age=200, measures=20100, date=latest. Day-one verified row: E14001204, Dudley, 104,687 people, 2024.
- **Health and housing work using official ONS small-area components.** https://ons-dp-prod-cdn.s3.eu-west-2.amazonaws.com/maptiles/ap-geos/v4/E14/E14001204.json (the geography lookup used by ONS custom area profiles) contains a compressed partition of 42 non-overlapping OAs/LSOAs/MSOAs in its oa21cds field. Use ONLY this one partition, not the other lsoa21cds/msoa21cds lists, which overlap. Nomis NM_2055_1 (general health) and NM_2072_1 (housing tenure) return all126 required cells each when geography is the comma-separated 42 GSS codes, date=2021, measures=20100, category cells0,4,5. A strict validator rejects missing/duplicate/unexpected area-category cells, wrong periods/measures, invalid or suppressed observations and invalid denominators. Aggregated health: 6,751/100,977 residents self-rating bad or very bad health =6.7%; housing:10,504/41,612 households social-rented =25.2%. Current constituency boundaries approximated from Census output areas. Mixed-area published totals can differ slightly from constituency totals because of statistical disclosure control; explicitly noted on site. No old-boundary constituency is used. Independent profile_census source prevents a Census feed failure from blocking current employment/population/claimant updates.
- Six parser/retention tests pass, including partition selection avoiding duplicate aggregation, missing/duplicate observations, cross-month council schedules and per-feed stale retention.

Parliament petitions API works. Dudley's current ONS constituency code is E14001204, verified against the official constituency breakdown of petition 767687 (MP Sonia Kumar MP). Listing pages omit constituency counts; individual petition JSON provides them. The implementation scans every open listing page, sorts by national count, then retrieves individual constituency breakdowns in batches until all remaining petitions' national totals are below the tenth-highest Dudley count. This is an exact upper-bound elimination, not a national-popularity shortlist. Four concurrent requests; details cached by source updated_at. Failures preserve the prior complete public snapshot while saving private cache progress. The live API does not provide a frozen transactional snapshot, noted in displayed methodology.
